# SQL ile E-Veri Analizi (Olist Dataset)

Bu klasörde, Olist Brezilya E-Ticaret veri seti kullanılarak Neon Console (SQL Editor) üzerinde gerçekleştirilen SQL sorgulama ödevine ait kodlar ve sonuçlar yer almaktadır.

## Ödev İçeriği ve Konular
- Filtreleme ve Sıralama (`WHERE`, `ORDER BY`, `LIMIT`)
- Benzersiz Değerler ve Sayımlar (`DISTINCT`, `COUNT`)
- Gruplama ve Koşullu Filtreleme (`GROUP BY`, `HAVING`)
- Tablo Birleştirme İşlemleri (`JOIN`, `LEFT JOIN`)
- İstatistiksel Hesaplamalar (`SUM`, `AVG`, `ROUND`)
